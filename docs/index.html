Game bắn tăng 2D realtime nhiều người, chơi trên trình duyệt & điện thoại. Giao diện máy cầm tay cổ điển: màn hình LCD ở trên, D-pad + nút bắn ở dưới. Lấy cảm hứng từ huyền thoại Battle City / Tank 1990.

Tính năng

Đầy đủ cơ chế của dòng game bắn tăng cổ điển, viết lại từ đầu.

🎮

Máy điện tử băng

Khung máy cầm tay, màn hình LCD có scanline, D-pad + nút BẮN cỡ lớn — tối ưu cho cảm ứng.

🌐

Co-op realtime

Tối đa 4 người cùng phòng qua WebSocket. Server giữ trạng thái chuẩn, đồng bộ mượt.

🦅

Bảo vệ đại bàng

Giữ căn cứ, diệt 20 xe địch mỗi màn qua 3 màn với địa hình khác nhau.

⭐

6 vật phẩm

Ngôi sao, đồng hồ, xẻng, lựu đạn, mũ giáp, thêm mạng — bắn xe nhấp nháy để nhận.

🧱

Địa hình đa dạng

Gạch vỡ được, thép cứng, nước chặn xe, bụi cây che khuất — chiến thuật thật sự.

🤖

4 loại xe địch

Basic, Fast, Power (bắn nhanh), Armor (4 giáp). Xe nhấp nháy mang vật phẩm.

Ảnh chụp

Chụp trực tiếp từ game đang chạy.

Cách chơi

Điều khiển

  • Điện thoại: D-pad để di chuyển, nút BẮN (giữ = bắn liên tục).
  • Máy tính: ↑ ↓ ← → / W A S D di chuyển, Space bắn.
  • START: vào trận / chơi lại.

Chơi co-op nhiều người

git clone https://github.com/phanngoc/tank-battle-90.git
cd tank-battle-90
npm install
npm start   # → http://localhost:3000
  • Mở URL LAN trên nhiều điện thoại/máy cùng Wi-Fi → vào chung một trận.
